# 重返游乐园 · 3D经营模拟器

[当前可玩的游戏](https://evergreen-park-3d-bz.bzhku.chatgpt.site/)

GitHub Pages暂未启用，待确定使用的账号或组织后再发布。

买下一座废弃游乐园，从园区中央开始，慢慢翻修60处固定设施。门票、特快通道、项目收费、排队容量和游客评价共同影响经营。各项目有多条升级路线，升级会改变3D外观。

- WASD：前后左右移动；方向键：转头。
- 鼠标拖拽：转向；点击场景空白处：锁定鼠标；Esc：释放。
- 点击建筑或设施列表：翻修、升级、调价及查看评价。
- 新局10,000金币，标准速度一个营业日约20分钟。
- 进度自动保存在当前浏览器；帮助→存档管理可导出、导入。

## 存档迁移

旧网址的进度不会自动出现在新网址。先在旧游戏导出存档文件，再到这个网址导入。各设备与浏览器的进度独立，不提供账号云同步。

## 发布与维护

这是纯HTML/CSS/JavaScript静态游戏，无需构建或服务器。GitHub Pages使用main分支根目录发布。修改对应文件并推送后，Pages会自动重新部署。测试可在此目录运行 `python3 -m http.server 8773 --bind 127.0.0.1`。

Three.js r170随游戏提供，许可证见 [vendor/THREE-LICENSE.txt](vendor/THREE-LICENSE.txt)。
